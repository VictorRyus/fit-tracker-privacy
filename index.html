01

수집하는 개인정보 항목 및 수집 방법

본 앱(FitTracker)은 사용자에게 원활한 서비스를 제공하기 위해 아래의 정보를 수집합니다.

수집 항목 수집 방법 비고
이메일 주소, 프로필 이름, 프로필 사진 Google 로그인 (Firebase Auth) 사용자 식별
Gemini API 키 사용자 직접 입력 본인이 직접 발급한 키, 본인 서비스에만 사용
걸음 수, 이동 거리, 체중, 소모 칼로리, 신장 Health Connect 연동 (사용자 권한 허용 시) 건강 데이터
키, 체중, 나이 사용자 직접 입력 신체 정보
기기 광고 식별자(GAID), 앱 오류 로그 자동 수집 (Google AdMob / Firebase) 광고 및 오류 분석
구독 영수증, 구매 식별자 인앱 결제 시 자동 수집 (RevenueCat) 구독 상태 관리
02

개인정보의 수집 및 이용 목적 / 보관 방법 및 기간

항목 이용 목적 보관 방법 보관 기간
Google 계정 정보 사용자 인증 및 식별 Firebase Authentication 회원 탈퇴 시까지
Gemini API 키 AI 헬스 코칭 서비스 제공 (사용자 본인 계정에만 사용) AES-256 암호화 후 Firebase Firestore 저장 회원 탈퇴 시 즉시 파기
Health Connect 데이터 건강 통계 시각화 및 AI 코칭 맞춤 데이터 제공 기기 내 Health Connect 앱을 통해 관리. AI 코칭 기능 사용 시 분석 목적으로 Gemini API에 전송될 수 있음 사용자가 Health Connect 권한 취소 시 즉시 중단
신체 정보 (키, 체중, 나이) BMI 기반 맞춤 가이드라인 제공 Firebase Firestore 저장 회원 탈퇴 시 즉시 파기
광고 식별자(GAID) 맞춤형 인앱 배너 광고 제공 (Google AdMob) Google AdMob 서버 Google 정책에 따름
구독 영수증, 구매 식별자 구독 상태 확인 및 결제 처리 RevenueCat 서버 RevenueCat 정책에 따름
Gemini API 키 안내: 본 앱이 수집하는 Gemini API 키는 사용자가 Google AI Studio에서 직접 발급한 키로, 해당 사용자 본인의 AI 코칭 서비스에만 사용됩니다. 제3자에게 제공되거나 다른 목적으로 사용되지 않습니다.
Health Connect 데이터 처리 안내: Health Connect 데이터는 기본적으로 기기 내에서만 관리됩니다. 단, AI 코칭 기능 이용 시 해당 데이터의 일부가 분석 목적으로 Google Gemini API 서버에 전송될 수 있습니다. 이 기능은 사용자가 직접 실행할 때에만 동작합니다.
03

개인정보의 제3자 제공

원칙적으로 본 앱은 사용자의 개인정보를 외부에 제공하지 않습니다. 다만, 원활한 서비스 제공을 위해 아래의 외부 시스템과 연동하며, 각 서비스에 필요한 최소한의 데이터만 전달됩니다.

제공받는 자 제공 목적 제공 항목 보유 기간
Google LLC (Firebase) 인증, 데이터 저장, 오류 분석 계정 정보, Gemini API 키(암호화), 신체 정보 회원 탈퇴 시까지
Google LLC (AdMob) 맞춤형 광고 제공 기기 광고 식별자(GAID), 앱 사용 정보 Google 정책에 따름
Google LLC (Gemini API) AI 헬스 코칭 분석 사용자가 입력한 건강 데이터 (AI 기능 실행 시에만) 요청 처리 후 즉시 파기
Google LLC (Health Connect) 건강 데이터 연동 걸음 수, 이동 거리, 체중, 소모 칼로리, 신장 권한 취소 시까지
RevenueCat Inc. 구독 결제 처리 및 상태 관리 구독 영수증, 기기 식별자, 구매 정보 RevenueCat 정책에 따름

· Google 개인정보처리방침: policies.google.com/privacy
· RevenueCat 개인정보처리방침: revenuecat.com/privacy

04

개인정보의 파기 절차 및 방법

앱은 개인정보 보유 기간이 경과하거나 처리 목적이 달성된 경우 해당 정보를 지체 없이 파기합니다.

상황 파기 범위 처리 기간
회원 탈퇴 또는 계정 삭제 요청 Firebase에 저장된 모든 데이터 (계정, API 키, 신체 정보 등) 7일 이내
Health Connect 권한 취소 앱의 Health Connect 데이터 접근 및 수집 즉시 중단 즉시
로그아웃 앱 내 세션 종료, 서버 데이터는 유지 즉시
앱 삭제 주의: 기기에서 앱을 삭제하더라도 Firebase 서버에 저장된 데이터는 자동 삭제되지 않습니다. 완전한 데이터 삭제를 원하시면 앱 내 계정 삭제 기능을 이용하거나 아래 이메일로 삭제를 요청해 주세요.

전자 파일: Firebase Admin API를 통해 복구 불가능한 방식으로 영구 삭제
